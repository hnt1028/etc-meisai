# 用語集（ユビキタス言語）

UI・文書では **日本語**、コードの識別子（変数・関数・クラス名）では **英語** を使う。ここに無い言葉を新しく作るときは、そのブランチの作業内で用語集へ追加する（`rule` ブランチに限らず、どのブランチでも追加できる）。追加した用語は、その変更と同じコミットに含める。

「CSV上の列名」は利用明細CSVのヘッダーに出てくる表記をそのまま書く（全角・半角を含む）。CSVに対応する列が無い用語は「-」とする。

## 明細・利用

| 日本語 | CSV上の列名 | 英語（識別子） | 意味 |
|---|---|---|---|
| 利用明細 | - | `Statement` | 取り込んだCSV全体。明細行の集まり |
| 明細行 | - | `StatementLine` | 利用明細の1明細。入口から出口までの1回の利用で、CSVの1行に相当する |
| 入口日時 | 利用年月日（自）・時分（自） | `entranceAt` | 明細行の入口を通過した日時。CSVで空欄のときは、利用者が1回だけ入力できる（入力した値は別に保存する） |
| 出口日時 | 利用年月日（至）・時分（至） | `exitAt` | 明細行の出口を通過した日時 |
| ID | - | `id` | 保存した明細行を識別するUUIDv7。重複判定には使わない |
| 重複判定キー | - | `duplicateKey` | 同じ明細行かを判定する文字列。入口日時・入口IC・出口IC・ETCカード番号をつなぐ。CSVの値だけで作る（利用者が入力した値は使わない）（[csv-format.md](csv-format.md)） |
| 状態 | 備考 | `status` | 確定か確認中のどちらか。備考欄の一部で、`ConfirmationStatusValue` で表す |
| 取込 | - | `import` | 利用明細CSVを端末内に読み込むこと |
| 確定 | 備考 | `confirmed` | 金額が最終的に決まった状態。備考欄に含まれる |
| 確認中 | 備考 | `pending` | 割引や通行止めの調整が反映される前の状態。備考欄に含まれる |
| 割引種別 | 備考 | `discountType` | 深夜割引、休日割引など。備考欄に含まれる（状態とは別物） |
| 利用明細一覧 | - | `statementList` | 明細行を並べて表示する画面と、その内容 |
| 詳細 | - | `detail` | 1件の明細行のすべての項目を表示する画面とその内容 |
| タイムライン | - | `timeline` | 1日を時間軸にして、明細行を入口から出口までの帯で並べる表示 |
| 絞り込み | - | `filter` | 一覧に出す明細行を、期間・車両番号・ETCカード番号で選ぶこと |
| 選択肢 | - | `choices` | 絞り込みで選べる値（車両番号、ETCカード番号の下4桁）。取り込み済みの全明細行から集める |
| 期間 | - | `period` | 絞り込みの日付の範囲。出口日時の日付で比較する |

## IC・ルート

| 日本語 | CSV上の列名 | 英語（識別子） | 意味 |
|---|---|---|---|
| 入口IC | 利用ＩＣ（自） | `entranceIc` | 明細行の入口にあたるIC |
| 出口IC | 利用ＩＣ（至） | `exitIc` | 明細行の出口にあたるIC |
| ICマスタ | - | `IcMaster` | IC名・座標・路線名の対応表（アプリ同梱。出どころは [route-map.md](route-map.md)） |
| IC地点 | - | `IcPoint` | ICマスタの1件。IC・JCT・スマートIC・PAなどの1地点 |
| IC種別 | - | `IcKind` | 一般IC、スマートIC、JCT、その他。`IcKindValue` で表す |
| 路線名 | - | `routeName` | 高速道路・自動車専用道路の名前（例: 東名高速道路）。IC地点が載っている路線 |
| 対応づけ | - | `icMapping` | CSVのIC名と、IC地点を結びつけること。利用者が登録したもの |
| 一致状態 | - | `IcMatch` | IC名がIC地点に決まるかどうか。一致・複数候補・未一致。`IcMatchValue` で表す |
| 位置不明 | - | `unknownLocation` | ICマスタに無く、地図に描けない区間 |
| ルート | - | `route` | 明細行の入口ICから出口ICまでの経路 |
| ルートマップ | - | `routeMap` | 期間の全明細行のルートを、地図上に並べる画面 |
| 区間 | - | `segment` | 地図に描く、明細行1件分の入口から出口までの直線 |
| 位置の指定 | - | `icPosition` | 利用者が地図をタップして決めた、IC名の位置。マスタの位置より優先する |
| 近似 | - | `approximate` | 料金所（…本線）や、上り・下りなどが付いたIC名（永福上）の位置が、IC地点の位置を借りたものであること |

## 料金

| 日本語 | CSV上の列名 | 英語（識別子） | 意味 |
|---|---|---|---|
| 割引前料金 | 割引前料金 | `grossFare` | 割引前の金額（円） |
| ETC割引額 | ＥＴＣ割引額 | `etcDiscount` | ETCの割引額（円） |
| 通行料金 | 通行料金 | `fare` | 割引後に支払う金額（円）。割引前料金からETC割引額を差し引いた額。還元額適用料金と後納料金の合計 |
| 還元額 | - | `rebate` | ETCマイレージでポイントを交換して得る金額（円）。CSVに専用の列は無い |
| 還元額適用料金 | 還元額適用料金 | `fareAfterRebate` | 通行料金のうち、還元額で充当された部分（円） |
| 合計金額 | - | `totalFare` | 絞り込んだ明細行の通行料金の合計（円）。内訳は、還元額適用料金の合計 `totalFareAfterRebate` と、後納料金の合計 `totalPostpaidFare` |
| 後納料金 | 後納料金 | `postpaidFare` | 通行料金のうち、ETCカードに後日請求される部分（円） |

## 車両・カード

| 日本語 | CSV上の列名 | 英語（識別子） | 意味 |
|---|---|---|---|
| 車種 | 車種 | `vehicleType` | 車両の種類。CSVの1〜5の番号で、事業者に合う名前（普通車・大型車・特大車・中型車・軽自動車等、大型Ⅰなど）に変換する（[vehicle-types.md](vehicle-types.md)）。決められないときは、`VehicleTypeValue` の名前 |
| 車両番号 | 車両番号 | `vehicleNumber` | 車のナンバープレートの番号（数字。個人情報）。CSVで空欄のときは `null`（車両番号なし）。利用者が1回だけ入力できる |
| ETCカード番号 | ＥＴＣカード番号 | `cardNumber` | ETCカードを識別する番号（個人情報） |
| ETCカード番号の下4桁 | - | `cardNumberSuffix` | ETCカード番号の末尾4文字。画面にはこれだけを表示する |
| 備考 | 備考 | `note` | 状態（確定・確認中など）と割引種別を `;` 区切りで並べた文字列 |

## 集計

| 日本語 | CSV上の列名 | 英語（識別子） | 意味 |
|---|---|---|---|
| 集計 | - | `aggregation` | 絞り込んだ明細行を、種類ごとにまとめて数えること（[aggregation.md](aggregation.md)） |
| 回数 | - | `count` | 集計で数える明細行の数 |
| 利用額 | - | `fare` の合計 | 集計での、通行料金の合計（円）。明細行の `fare` と同じ語を使う |
| 割引額 | ＥＴＣ割引額 | `discount` | 集計での、ETC割引額の絶対値の合計（円）。割引なしは 0 円 |
| 距離 | - | `distance` | 集計での、入口ICから出口ICまでの道のりの合計（メートル）。推定（[aggregation.md](aggregation.md)） |
| リンク | - | `link` | ICマスタで、道路に沿って隣り合う2つの地点と、その間の道のり（メートル）。距離を求める道路の網の辺 |
| 事業者 | - | `operator` | 道路を運営する会社・公社（NEXCO東日本、首都高速道路など）。CSVに無く、路線名から推定する |
| メモ | - | `memo` | 利用者が明細行に書く、短い文章（200文字まで）。CSVには無い |
| タグ | - | `tag` | 利用者が明細行に付ける印（「仕事」「私用」など）。1つの明細行に、10個まで。絞り込みと集計に使う |
| 走破率 | - | `coverage` | 路線の区間のうち、走った区間の道のりの割合。集計画面の「走破率」で、路線ごとに出す（[aggregation.md](aggregation.md)） |
| 路線図 | - | `network` | ICマスタのすべての道路を、薄い灰色の線で結んだもの。ルートマップの「地図の表示」で、出し入れできる |
| 地図の表示 | - | `routeMapLayer` | ルートマップに表示する項目（路線図、路線図の路線名、走行した路線図、ICのマーカー、確認中の線、走行回数による太さ）。利用者が、項目ごとに選ぶ |
| 線の色 | - | `operatorColor` | 地図の線の色。道路の事業者ごとに決める。初期値があり、利用者が設定で変えられる（[route-map.md](route-map.md)） |
| 時間帯 | - | `hour` | 出口の時刻の「時」（0〜23） |
| 棒グラフ | - | `bars` | 値の大きさを横棒の長さで表すグラフ（期間別・時間帯別） |
| 円グラフ | - | `pie` | 全体に対する割合を扇形で表すグラフ（事業者別・路線別・IC別・割引種別別） |
| その他 | - | `other` | 円グラフで、上位10件に入らなかった路線・ICをまとめた扇形 |

## バックアップ

| 日本語 | CSV上の列名 | 英語（識別子） | 意味 |
|---|---|---|---|
| バックアップ | - | `backup` | 保存したすべてのデータ（明細行、ICの対応づけ、ICの位置の指定）を、1つのファイルにしたもの（[backup-format.md](backup-format.md)） |
| 書き出し | - | `export` | バックアップを作って、ファイルに保存すること |
| 読み込み | - | `import` | バックアップを読んで、すべてのデータを置き換えること。「取込」（CSVを足すこと）とは別 |

## 注意

- 「料金」は必ず上の種類のどれかを指す。単に「料金」と書かない
- 金額はすべて `int`（円）で扱う（CLAUDE.md の基本ルールに従う）
- クラス名とファイル名には、種類を示す接尾辞を付ける（[architecture.md](architecture.md) の「命名」）。上の表の英語は、接尾辞を付ける前の語幹を指す
- 英語の識別子は上の表に従う。表に無い英語の名前を勝手に作らない
