# 集計の定義と事業者の推定

集計画面（[SCR-006](systems/screens/SCR-006-aggregation.md)、[PRC-013](systems/processes/PRC-013-aggregate-statements.md)）で、何をどう数えるかを決める。

## 数える対象

- 絞り込み（期間・車両番号・ETCカード番号）に合う明細行。絞り込みは、利用明細一覧・ルートマップと同じ（出口日時の日付で比較する）
- 状態（確定・確認中）は区別せず、すべて数える

## 値の定義

| 名前 | 定義 |
|---|---|
| 回数 | 明細行の数 |
| 利用額 | 通行料金（`fare`）の合計（円） |
| 割引額 | ETC割引額（`etcDiscount`。CSVでは負の数）の絶対値の合計（円）。空欄（割引なし）は 0 円 |
| 距離 | 明細行の入口ICから出口ICまでの道のりの合計（メートル。画面には km で表示する）。決め方は下の「距離の求め方」 |

## 集計の種類

| 種類 | 行 | 回数 | 利用額 | 割引額 | 並び順・件数 |
|---|---|---|---|---|---|
| 期間別 | 週・月・年（利用者が切り替える） | ○ | ○ | ○（距離も ○） | 新しい期間が先。すべて |
| 事業者別 | 道路事業者 | ○ | ○ | ○（距離も ○） | 利用額の多い順。すべて |
| 路線別 | 路線名 | ○ | - | - | 回数の多い順、同数は名前順。上位10件 |
| IC別 | IC名 | ○ | - | - | 同上 |
| 時間帯別 | 0〜23時 | ○ | ○ | ○（距離も ○） | 0時から23時まで。すべて（0回の時間帯も出す） |
| 割引種別別 | 割引種別 | ○ | - | ○ | 回数の多い順、同数は名前順。すべて |
| タグ別 | タグ（利用者が付けたもの。付けていない明細行は「タグなし」） | ○ | ○ | ○ | 利用額の多い順。すべて。タグが複数ある明細行は、それぞれのタグに数える（合計は、全体と一致しない） |

- 期間の基準は、出口日時。週は、月曜日から始まる週（行の名前は、その週の月曜日の日付）。時間帯は、出口の時刻の「時」
- 1つの明細行が複数の行に入るもの（路線別・IC別・割引種別別）は、利用額と割引額を出さない（二重に数えるため）。割引種別別の割引額は、その種別が付いた明細行の割引額の合計で、種別を複数持つ明細行は、それぞれの種別に含む
- IC別は、入口ICと出口ICを数える。同じ明細行で入口と出口が同じIC名のときは、1回。入口が空欄のときは、出口だけ
- 路線別は、明細行の路線名（[route-map.md](route-map.md) の「路線名」）ごとに数える。路線名が決められない明細行は、数えない
- 距離は、期間別・事業者別・時間帯別と、合計に出す。路線別・IC別・割引種別別には出さない（路線別・IC別は、1つの明細行が複数の行に入るため。割引種別別は、距離に意味が無いため）

## 距離の求め方

明細行ごとに、入口ICから出口ICまでの距離（メートル）を、次の順で決める。

1. 入口ICと出口ICの両方が、ICマスタの地点に決まるとき（自動の一致、対応づけ。末尾の上下などを除いた近似の一致も含む）は、2つの地点の間の距離（[route-map.md](route-map.md) の「地点の間の距離」）。入口と出口が同じ地点のときは 0
2. そうでなく、両方の位置が分かるとき（利用者が地図で指定した位置を含む。指定した位置があるICは、地図の位置を優先するため、地点が決まっていてもこちらになる）は、2つの位置の直線距離
3. どれでもないとき（入口が空欄、位置が分からないIC）は、距離が分からない。距離の合計に含めず、その明細行の数を「距離が分からない明細行」として数える

- この規則は、入口日時の目安（[PRC-016](systems/processes/PRC-016-estimate-entrance-at.md)）でも使う（実装は `lineMeters`）
- 距離は、道路に沿った道のりの推定である。実際の走行距離（ランプや料金所の出入り、迂回）とは違う。画面にも「推定」と表示する
- 事業者別の距離は、利用額と同じく、明細行を1つの行（事業者、または「複数の事業者」）に入れて足す

## グラフの形

| 種類 | グラフ | 理由 |
|---|---|---|
| 期間別、時間帯別 | 横棒 | 時間の流れ・並びで比べるため |
| 事業者別、路線別、IC別、割引種別別 | 円 | 全体に対する割合を見るため |

- 円グラフは、選んでいる値（回数・利用額・割引額・距離）の割合。値が0の行は、扇形にしない。すべて0のときは、円を描かず「表示できる値がありません」と出す
- 路線別・IC別は、上位10件の残りを「その他」の扇形にまとめる。割合の分母は、全体の合計（路線別は、路線ごとの回数の合計。IC別は、ICごとの回数の合計）。1つの明細行が複数の路線・ICに入るため、明細行の数とは一致しない
- 凡例に、名前・値・割合（小数1桁の%）を並べる。表の行と同じ名前を使う

## 道路事業者の推定

CSVに道路事業者の列は無く、国土数値情報（N06）にも事業者の情報は無い。そこで、**路線名から推定する**（実装は `routeOperatorOf`）。

- 明細行の事業者は、その明細行の路線名から決める。すべて同じ事業者ならその事業者、事業者の分かる路線が2つ以上の事業者にまたがるときは「複数の事業者」、事業者の分かる路線が無いときは「不明」
- 利用額は、明細行ごとに分けない（中央道から首都高速のように、事業者をまたぐ明細行の料金は、事業者ごとに分けられないため）。「複数の事業者」の行にまとめる
- 路線名の途中に、次の語を含むものを、上から順に調べる。最初に当たった事業者にする

| 路線名に含む語 | 事業者 |
|---|---|
| 首都高速 | 首都高速道路 |
| 阪神高速 | 阪神高速道路 |
| 名古屋高速 | 名古屋高速道路公社 |
| 福岡高速、北九州高速 | 福岡北九州高速道路公社 |
| 広島高速 | 広島高速道路公社 |
| 神戸淡路鳴門、西瀬戸、瀬戸中央 | 本州四国連絡高速道路 |
| 東京湾アクアライン | NEXCO東日本 |
| 東北、常磐、関越、東関東、北関東、館山、磐越、上信越、日本海東北、秋田、山形、三陸、北海道、道央、道東、札樽、外環、京葉、圏央道、首都圏中央 | NEXCO東日本 |
| 東名、第一東海、第二東海、新東名、中央、長野、東海北陸、伊勢湾岸、東海環状、中部横断、新湘南、能越、北陸、名神、新名神 | NEXCO中日本 |
| 近畿、山陽、中国、九州、長崎、大分、宮崎、東九州、関門、西九州、松山、高知、徳島、高松、四国、阪和、関西空港、京都縦貫、舞鶴若狭、西名阪、第二神明 | NEXCO西日本 |

- 路線の途中で事業者が変わるもの（北陸道、名神、圏央道など）は、主な事業者に固定する。**推定であり、正確な事業者別の料金ではない**。画面にも「推定」と表示する
- 表に当たらない路線は、事業者なし（「不明」になる）。必要に応じて、この表とコードの表を同時に直す
