# 仕様書

このアプリの振る舞いを定める文書。実装と同じ変更で更新する。
CSVの列の詳細は [csv-format.md](csv-format.md)、用語は [ubiquitous-language.md](ubiquitous-language.md)、地図の詳細は [route-map.md](route-map.md) を参照する（ここには書き写さない）。

## 1. 目的

ETC利用照会サービスの利用明細CSVを取り込み、利用の内容を一覧で確認し、どの区間を通ったかを地図で確認できるようにする。

## 2. データの取得

- 利用者が「ETC利用照会サービス」から利用明細CSVを出力し、アプリに取り込む
- アプリからサービスへの自動ログイン・データ取得はしない
- データは端末内にのみ保存する

## 3. 画面

### 3.1 利用明細一覧

- 取り込んだ利用（`Trip`）を一覧で表示する
- 表示項目: 入口日時、出口日時、入口IC、出口IC、通行料金、状態（確定・確認中）
- 絞り込み: 期間、車両番号、ETCカード番号
- 合計金額を表示する。内訳として、還元額適用料金と後納料金の合計も表示する
- ETCカード番号は下4桁のみ表示する
- 確認中の利用には、その旨を表示する

### 3.2 ルートマップ

- 一覧で選んだ利用、または期間の利用の経路を地図上に表示する
- 位置が分からないICの区間は地図に描かず、通知する（詳細は [route-map.md](route-map.md)）

### 3.3 設定

- 利用明細CSVの取り込み（ファイル選択、取り込み結果の件数表示）
- 取り込んだデータの削除
- 取り込みの規則（確定・確認中の上書き）は [csv-format.md](csv-format.md) に従う

## 4. 取り込み

- 文字コード、列、日付形式、重複判定、上書き規則は [csv-format.md](csv-format.md) に従う
- 取り込みに失敗したときは、何が不正かを示し、既存のデータを変えない

## 5. 非機能要件

- 個人情報の扱いは [privacy.md](privacy.md) に従う
