# 仕様書

このアプリの振る舞いを定める文書。実装と同じ変更で更新する。
CSVの列の詳細は [csv-format.md](csv-format.md)、用語は [ubiquitous-language.md](ubiquitous-language.md)、地図の詳細は [route-map.md](route-map.md) を参照する（ここには書き写さない）。

## 1. 目的

ETC利用照会サービスの利用明細CSVを取り込み、明細行の内容を一覧で確認し、どの区間を通ったかを地図で確認できるようにする。

## 2. データの取得

- 利用者が「ETC利用照会サービス」から利用明細CSVを出力し、アプリに取り込む
- アプリからサービスへの自動ログイン・データ取得はしない
- データは端末内にのみ保存する

## 3. 画面

### 3.1 利用明細一覧

- 取り込んだ明細行（`StatementLineEntity`）を一覧で表示する。並び順は、出口日時の新しい順
- 表示項目: 入口日時、出口日時、入口IC、出口IC、通行料金、状態（確定・確認中）、割引種別。入口が空欄の明細行は、入口日時と入口ICを「-」で表示する
- 割引種別（深夜割引、休日割引など）が付いた明細行には、その名前を表示する
- 通行した高速道路（路線名）が分かる明細行には、その路線名を表示する（決め方は [route-map.md](route-map.md)）。入口が空欄でも、出口から分かれば表示する。東京湾アクアラインのように、ICマスタに無い路線も、IC名から決める
- 一覧の表示は、「一覧」と「タイムライン」を切り替えられる（3.1.1）。絞り込みと合計金額は、どちらの表示でも同じ
- 明細行をタップすると、その明細行の詳細を表示する（3.4）
- 絞り込み: 期間、車両番号、ETCカード番号
  - 期間は、出口日時の日付で比較する（開始日と終了日を含む）。日付を選んで指定する
  - 車両番号とETCカード番号は、取り込み済みの値から選ぶ
  - 絞り込みを解除して、すべての明細行に戻せる
- 合計金額を表示する。内訳として、還元額適用料金と後納料金の合計も表示する。合計は、絞り込んだ明細行について計算する（確認中の明細行も含める）
- ETCカード番号は下4桁のみ表示する
- 確認中の明細行には、その旨を表示する
- 明細行が1件も無いときと、絞り込みで0件になったときは、それぞれ別の文言を表示する
- CSVの取り込みや削除をしたあとは、一覧の内容を最新にする

#### 3.1.1 タイムライン表示

- 1日を時間軸（0時〜24時）にした図で、その日の明細行を、入口から出口までの帯で表示する。明細行ごとに1行で、入口時刻の早い順に並べる
- 表示する日を、前の利用日・次の利用日へ移れる（明細行が無い日は飛ばす）。最初は、絞り込み後の最新の利用日を表示する
- 日をまたぐ明細行は、その日の範囲だけを帯にする。入口が空欄の明細行は、出口の時刻に印だけを表示する
- 確認中の明細行は、帯の見た目を変える
- 帯をタップすると、詳細を表示する（3.4）

### 3.2 ルートマップ

- 期間の全明細行の経路を、地図上に表示する。絞り込み（期間・車両番号・ETCカード番号）は、利用明細一覧（3.1）と共通。期間を指定しないときは、すべての明細行
- 経路は、明細行ごとの、入口ICから出口ICまでの直線。確定は実線、確認中は破線。同じ区間は重ねて描く
- ICと料金所には、名前つきのマーカーを表示する
- 位置が分からないICの区間（入口が空欄の明細行を含む）は描かず、地図の上部に通知する（位置不明のIC数と、描けない明細行数）
- 位置不明のIC、または位置を直したいIC・料金所は、利用者が地図をタップして位置を指定する。指定した位置は、端末内にだけ保存し、マスタの位置より優先する。指定は解除できる。登録・解除したあとは、一覧・詳細の路線名にも反映する
- 「…本線」（料金所）と、IC名に上り・下りなどが付くもの（「永福上」など）の位置は、初めはIC地点の近似になる（[route-map.md](route-map.md)）。指定で正確にできる
- 線をタップすると、その明細行の詳細（3.4）を表示する。同じ場所に複数の線があるときは、選んで開く
- マーカーをタップすると、そのICの情報（名前、路線名、位置の種類）を表示し、位置を指定・解除できる
- 地図は OpenStreetMap を使う。外部通信は、地図タイルの取得だけ（[privacy.md](privacy.md)）。「© OpenStreetMap contributors」を表示する

### 3.3 設定

- 利用明細CSVの取り込み（ファイル選択、取り込み結果の件数表示）
- 取り込んだデータの削除
- ICの対応づけ（3.5）への入口
- ICマスタの出典の表示（[route-map.md](route-map.md)）
- 取り込みの規則（確定・確認中の上書き）は [csv-format.md](csv-format.md) に従う

### 3.4 利用明細詳細

- 一覧またはタイムラインで選んだ明細行の、すべての項目を表示する
- 表示項目: 入口日時、出口日時、入口IC、出口IC、通行した高速道路（路線名）、割引前料金、ETC割引額、通行料金、還元額適用料金、後納料金、車種、車両番号、ETCカード番号（下4桁のみ）、状態、割引種別
- 割引前料金とETC割引額は、CSVで空欄（割引なし）のとき「-」で表示する
- 通行した高速道路（路線名）。分からないときは「-」で表示する
- 項目の上に、その明細行のルートを地図で表示する。入口ICから出口ICまでの線（確定は実線、確認中は破線）と、入口・出口のマーカーを描き、地図全体を収める。地図の表示のしかたは、ルートマップ（3.2）と同じ
  - 位置が分からないICがあるときは、地図の上に「位置が分からないICがあります」と、そのIC名を示す（線は描けない）。位置は、ルートマップ（3.2）で指定できる。マーカーが1つも無いときは、地図を表示しない
  - 入口が空欄のときは線を描かず、出口のマーカーだけを描く

### 3.5 ICの対応づけ

- CSVのIC名を、ICマスタの地点（座標と路線名を持つ）に結びつける。多くは自動で一致する（規則は [route-map.md](route-map.md)）
- 自動で一つに決まらないIC名（複数候補、未一致）を一覧し、利用者が、地点を探して選び、対応づけを登録する
- 登録した対応づけは、端末内にだけ保存する。一覧から解除できる。登録すると、一覧・詳細・ルートマップに反映する
- 登録した対応づけは、自動の一致より優先する

### 3.6 画面の移動

- 画面下のナビゲーションバーで、「利用明細」（3.1）、「ルートマップ」（3.2）、「設定」（3.3）を切り替える。起動時は「利用明細」を表示する
- 利用明細の一覧またはタイムラインから、明細行をタップして詳細（3.4）へ移る。戻るボタンで、元の表示に戻る
- 設定（3.3）から、ICの対応づけ（3.5）へ移る。戻るボタンで、設定に戻る
- ルートマップの線から、詳細（3.4）へ移る。戻るボタンで、ルートマップに戻る

## 4. 取り込み

- 文字コード、列、日付形式、重複判定、上書き規則は [csv-format.md](csv-format.md) に従う
- 取り込みに失敗したときは、何が不正かを示し、既存のデータを変えない
- 車種は、CSVの番号（1〜5）を保存し、表示するときに名前へ変換する。名前は NEXCO の「車種区分１」に基づく（[TBL-001](systems/tables/TBL-001-statement-lines.md) の「車種の値」）
  - 道路事業者によって、同じ番号に別の名前が付く。CSVに事業者は出ないため、現時点では区分１の名前に固定する
  - 将来、ICマスタで道路事業者を判別できるようにしたうえで、事業者ごとの対応表に拡張する。番号を保存しているので、拡張してもデータの移行は要らない

## 5. 非機能要件

- 個人情報の扱いは [privacy.md](privacy.md) に従う
