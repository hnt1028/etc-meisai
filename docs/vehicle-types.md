# 車種区分（車種の名前）

CSV の「車種」は、1〜5 の番号である。番号の名前（普通車など）は、道路事業者（と、NEXCO では道路）ごとに違う。ETC利用照会サービスの[表示内容の説明](https://www.etc-meisai.jp/soukou_meisai_exp.html)の「車種」の表が、その対応を示す。このアプリは、その表をマスタにして、明細行ごとに、事業者に合う名前を表示する。

## マスタ

`assets/vehicle_type_master.json`（アプリに同梱）。表示内容の説明の「車種」の表を、そのまま写したもの。

```json
{
 "source": "https://www.etc-meisai.jp/soukou_meisai_exp.html",
 "divisions": [
  {"id": "nexco-1", "operators": ["NEXCO東日本", "NEXCO中日本", "NEXCO西日本"], "roads": [], "names": ["普通車", "大型車", "特大車", "中型車", "軽自動車等"]}
 ]
}
```

| 項目 | 意味 |
|---|---|
| `id` | 区分の名前（NEXCO は `nexco-1`〜`nexco-3`。他は事業者名） |
| `operators` | 区分が当てはまる道路事業者。[aggregation.md](aggregation.md) の「道路事業者の推定」の事業者名（表に無い公社は、表示内容の説明の名前） |
| `roads` | 区分が、その道路だけに当てはまるときの、道路名の語。空は、事業者の他の道路すべて |
| `names` | 車種番号 1〜5 の名前（この順）。`null` は、その区分に無い番号 |

- 区分は、26個（NEXCO 3社が共通の区分1・2・3、首都高速道路、阪神高速道路、本州四国連絡高速道路、名古屋高速道路公社、広島高速道路公社、福岡北九州高速道路公社、各県・市の道路公社など）
- NEXCO の区分2・3は、一般有料道路のうち、次の道路（表示内容の説明の「車種区分ごとの道路名」）
  - 区分2: 東富士五湖道路、広島岩国道路、椎田道路、武雄佐世保道路（西九州自動車道）、延岡南道路
  - 区分3: 長崎バイパス
  - 区分1: それ以外の、高速国道全線と一般有料道路
- 表示内容の説明が変わったら、マスタも直す（表の見出し、番号、名前を、表と照合する）

## 名前の決め方

実装は `lib/application/usecase/statements/vehicle_type_name.dart` の `vehicleTypeNameOf`。明細行の路線名（[route-map.md](route-map.md) の「路線名」）から、次の順で区分を決め、車種番号の名前を返す。

1. 路線名に、`roads` の語を含む道路があるとき、その区分（NEXCO の区分2・3）
2. なければ、路線名の事業者（[aggregation.md](aggregation.md) の「道路事業者の推定」。複数の事業者、または不明のときは、事業者なし）の区分のうち、`roads` が空のもの
3. 区分が決まらないとき、または、その区分にその番号の名前が無い（`null`）ときは、標準の名前（`VehicleTypeValue.label`。NEXCO の区分1の名前）

- 事業者は、路線名からの推定（CSV に事業者が無いため）。県・市の道路公社などは、路線名からは決められず、標準の名前になる
- 区分に無い番号が出たときは、区分の決め方が実際と違う可能性がある。標準の名前を出す
- 保存するのは、番号だけ（名前は、表示のたびに決める）。ICマスタが変わると、名前も変わりうる
- 番号が1〜5でないときは、取込でエラーにする（[csv-format.md](csv-format.md)）
