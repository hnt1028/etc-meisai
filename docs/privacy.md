# プライバシー・セキュリティ

明細、車両番号、ETCカード番号は個人情報として扱う。

- 全データは端末内のみに保存し、外部送信しない（地図タイル取得を除く）
- 地図タイルは、端末のアプリの保存領域に保存する（オフラインで使うため。[route-map.md](route-map.md) の「保存したタイルの使い方」）。タイルには、利用者のデータは含まれない。見た場所が、保存したタイルから推測できる
- データの書き出しは、利用者が選んだ保存先に、利用者の操作でだけ行う（アプリが自動で送らない）。書き出したファイルは、暗号化しない個人情報なので、保管は利用者が注意する。画面にも、そのことを表示する（[backup-format.md](backup-format.md)）
- Android の通信の権限（`INTERNET`）は、地図タイルの取得のためだけに、`android/app/src/main/AndroidManifest.xml` で宣言する。リリース版にも必要（無いと、地図が出ない）
- 解析・クラッシュ通知などの外部SDKは、ユーザーの同意なしに追加しない
- ETCカード番号は画面では下4桁のみ表示する
- ログに明細内容・カード番号・車両番号を出力しない
- テストやサンプルは架空データのみ。実際の明細CSVはリポジトリに含めない（除外設定は [git.md](git.md)）
